# SURLS SEO Landing Pages

Generated production-oriented Thymeleaf HTML pages for the SURLS SEO/use-case set.

Each page:
- Uses the same `fragment/header :: header` include as the supplied home.html.
- Uses the same footer structure and links as home.html.
- Uses the same Manrope / monochrome visual language.
- Includes SEO metadata, canonical URL, Open Graph image reference, and WebPage JSON-LD.
- Is responsive and keyboard-friendly.
- Contains unique page-specific hero copy, intent, FAQ, audience framing, and internal-linking content.

Place these files in your Spring Boot Thymeleaf templates directory.
