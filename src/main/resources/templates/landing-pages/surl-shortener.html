Frequently asked

Clear answers before you ship.

What is a URL shortener?

A URL shortener turns a long destination into a compact link. SURLS adds lifecycle and access controls so the link can be managed after it is created.

Can I combine multiple controls?

Yes. SURLS is designed so lifecycle and access controls can be combined where the workflow requires more than one condition.

Can I use this from an application?

Yes. SURLS provides API-oriented link infrastructure so applications can create and manage links programmatically.

Can I use my own domain?

Custom-domain support lets you connect a domain, verify DNS, and create links using that domain.
