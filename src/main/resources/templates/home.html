Under the hood

Designed for high-throughput link generation.

The short-code engine pre-generates obfuscated Base62 codes using worker buckets, an epoch-based generator and Feistel permutation, keeping the hot creation path away from database-generated identifiers.

01Request

Your application sends a link creation request.

02Auth

API key validates the creation request.

03Code pool

Pre-buffered short codes are ready for allocation.

04Persistence

Link metadata and access records are stored in MariaDB.

05Delivery

Requests are resolved, checked, logged and delivered.
